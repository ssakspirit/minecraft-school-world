# 새학기 마크 학교 — 학교 활동 월드 (스티브코딩)

마인크래프트 **에듀케이션 에디션**에서 새 학기 학급 활동을 할 수 있는 학교 월드와 교사용 명령 팩입니다.
번호 받기, 교실 꾸미기, 학교 탐험 퀴즈, 반장 선거를 채팅 명령 몇 줄로 진행할 수 있습니다.

> 이 월드는 Mojang의 "Back to School!" 템플릿 위에 학교를 지어 만들었습니다.
> 비공식 자료이며 Mojang·Microsoft와 관련이 없습니다.

---

## 1. 내려받기와 설치

1. 오른쪽 **[Releases](../../releases)**에서 `school-world.mcworld`를 내려받습니다.
2. 파일을 **두 번 클릭**하면 마인크래프트 에듀케이션이 열리면서 월드를 가져옵니다.
   - 열리지 않으면: 마인크래프트 실행 → **플레이 → 가져오기** → 파일 선택
3. 월드를 열고 채팅창(`T` 키)에 아래 명령을 입력합니다.

```
/function setup
/function info
```

- `setup`은 처음 한 번만 실행합니다. 실행한 사람에게 교사 표시를 붙이고, 점수판과 안전 설정(불·폭발·PvP 끄기)을 만듭니다.
- `info`는 사용 안내를 채팅창에 보여 줍니다.

> 명령이 "알 수 없음"으로 나오면 **설정 → 치트 허용**이 켜져 있는지 확인하세요.
> 교사용 명령 팩(`새학기 학교 교사용 도구`)은 월드에 이미 들어 있습니다.

### 팩만 따로 쓰고 싶을 때

Releases의 `school_teacher_bp.mcpack`을 두 번 클릭해 가져온 뒤, 월드 설정 → **비헤이비어 팩**에서 켭니다.
번호 자리·투표실·교실 좌표가 이 월드에 맞춰져 있어서, 다른 월드에서는 일부 명령만 제대로 동작합니다.

## 3. 수업 기본 순서

```
/function class/gather       ① 운동장에 모으기
/function number/give        ② 번호 자리에 세운 뒤 번호 주기
/function room/go            ③ 자기 번호 교실로 보내기
/function class/build_on     ④ 블록 놓기 허용 → 교실 꾸미기
/function class/build_off    ⑤ 활동이 끝나면 다시 잠금
```

- **번호는 운동장 자리 기준입니다.** 1~6번은 첫째 줄, 7~12번은 둘째 줄, …, 25~30번은 다섯째 줄입니다.
  학생을 출석 번호 자리에 세우고 `number/give`를 실행하면 출석 번호가 그대로 학생 번호가 됩니다.
- **교실 번호는 학생 번호와 같습니다.** 투표실을 뺀 35개 교실이 있습니다.

| 건물 | 1층 | 2층 | 3층 |
|---|---|---|---|
| 1동 | 1 · 2 · 3 (투표실 제외) | 4 ~ 7 | 8 ~ 11 |
| 2동 | 12 ~ 15 | 16 ~ 19 | 20 ~ 23 |
| 3동 | 24 ~ 27 | 28 ~ 31 | 32 ~ 35 |

## 4. 전체 명령

모두 채팅창에 `/function 이름`으로 입력합니다. 학생은 슬래시 명령을 쓸 수 없으니 교사만 실행할 수 있습니다.

### 안내
| 명령 | 하는 일 |
|---|---|
| `info` | 사용 안내 첫 화면 (수업 순서 + 목차) |
| `info/number` · `info/room` · `info/quiz` · `info/vote` · `info/class` · `info/build` | 주제별 자세한 안내 |
| `help` | 짧은 명령 목록 |

### 번호·자리
| 명령 | 하는 일 |
|---|---|
| `number/give` | 운동장 번호 자리에 선 학생에게 그 자리 번호를 줌 (이름 아래·Esc 목록에 표시) |
| `number/show` · `number/hide` · `number/reset` | 번호 보이기 · 숨기기 · 지우기 |
| `seat/draw` | 학생 모두에게 겹치지 않는 **무작위** 자리 번호 |
| `seat/show` · `seat/hide` · `seat/reset` | 자리 번호 보이기 · 숨기기 · 지우기 |

### 교실 꾸미기
| 명령 | 하는 일 |
|---|---|
| `room/go` | 학생을 자기 번호 교실 한가운데로 이동 |
| `room/numbers_1_prepare` → `room/numbers_2_build` | 교실 번호판 다시 달기 (10초 간격) |
| `room/numbers_1_prepare` → `room/numbers_remove` | 교실 번호판 지우기 |

### 학교 탐험 퀴즈
| 명령 | 하는 일 |
|---|---|
| `quiz/show` · `quiz/hide` | 진행 상황 점수판 보이기 · 숨기기 |
| `quiz/reset` | 기록과 양털 모두 회수 (다음 반 수업 전에) |

학생이 NPC에게 말을 걸어 정답을 처음 맞히면 양털 1개와 진행도(n/16)를 받습니다. 16색을 다 모으면 전체 채팅에 축하 메시지가 나옵니다.

### 반장 선거
| 명령 | 하는 일 |
|---|---|
| `vote/setup` | 학생마다 투표권 1장 지급, 득표 0으로 |
| `vote/result` | 득표수 공개 (오른쪽 점수판) |
| `vote/hide` · `vote/reset` | 점수판 숨기기 · 처음부터 다시 |

학생은 투표실에 한 명씩 들어가 기호 버튼을 누릅니다. 투표권이 없으면 표가 세어지지 않아서 두 번 투표할 수 없습니다.

### 수업 관리
| 명령 | 하는 일 |
|---|---|
| `class/gather` · `class/classroom` | 운동장 · 견본 교실로 모두 모으기 |
| `class/adventure` · `class/creative` | 모험 모드(블록 못 부숨) · 크리에이티브 모드 |
| `class/build_on` · `class/build_off` | 블록 놓기 허용 · 잠금 |
| `class/safe` | 불·폭발·PvP·낙하 피해 끄기 (`setup` 때 자동 실행) |

### 건물 짓기 (참고용)
릴리즈 월드에는 이미 지어져 있습니다. 빈 템플릿에서 다시 지을 때만 씁니다.

| 명령 | 하는 일 |
|---|---|
| `build/b3_1_prepare` → `b3_2_build` → `b3_3_finish` | 2동을 서쪽에 복사해 3동 짓기 |
| `build/b4_1_prepare` → `b4_2_flatten` → `b4_3_campus` → `b4_4_street` → `b4_5_garden` → `b4_9_finish` | 3동 주변 평탄화, 학교 시설, 학교 앞 거리 |

> `b3_undo` · `b4_undo`는 지은 것을 지우고 **평평한 잔디**로 만듭니다. 원래 지형으로는 돌아가지 않으니 꼭 백업한 뒤 쓰세요.

## 5. NPC·커맨드 블록 고치기

퀴즈 NPC 버튼과 투표실 커맨드 블록은 게임 안에서 직접 고쳐야 합니다.
고치는 방법과 넣을 명령은 [docs/NPC명령_수정표.md](docs/NPC명령_수정표.md)에 있습니다.

## 6. 폴더 구조

```
school_teacher_bp/          교사용 명령 팩 (비헤이비어 팩)
├─ manifest.json
└─ functions/
   ├─ setup · help · info   처음 설정과 안내
   ├─ info/                 주제별 안내
   ├─ number/ · seat/       번호·자리 뽑기
   ├─ room/                 교실 번호판·교실 이동
   ├─ quiz/                 퀴즈 (q00~q15 양털, q16 보너스)
   ├─ vote/                 반장 선거
   ├─ class/                수업 관리
   └─ build/                3동·학교 주변 짓기
docs/                       NPC 수정표, 배치도
```
