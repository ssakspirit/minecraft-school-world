# 새학기마크학교 NPC·커맨드 블록 수정표

이 표대로 고치면 다음이 해결됩니다.
- 근처 다른 학생이 양털을 대신 받는 문제
- 정답을 반복해서 눌러 양털을 계속 받는 문제
- 정답·오답 안내가 30명 채팅에 모두 뜨는 문제
- 같은 학생이 두 번 투표하는 문제

정답 버튼은 월드에 새로 넣은 **교사용 도구 팩**의 함수를 부릅니다. 고치기 전에 아래 "0. 준비"를 먼저 해 주세요.

---

## 0. 준비 (한 번만)

1. 월드를 완전히 나갔다가 다시 엽니다. 새 팩은 월드를 다시 열어야 불러옵니다.
2. **설정 → 비헤이비어 팩 → 활성**에 **"새학기 학교 교사용 도구"**가 있는지 확인합니다.
3. 채팅창에 `/function setup`을 입력합니다. 교사 태그가 붙고, 점수판과 안전 설정이 만들어집니다.
4. `/function help`로 명령 목록이 뜨는지 확인합니다.
5. NPC를 고치려면 월드 빌더 권한이 필요합니다. `/wb` 또는 `/worldbuilder`를 입력하세요.
   - NPC를 오른쪽 클릭 → **고급 설정** → 버튼 편집에서 명령 칸을 통째로 바꿉니다.
6. **먼저 NPC 하나만 고쳐 보고** 양털이 들어오는지 확인한 뒤, 나머지를 고치세요.

> 백업: 바탕화면의 `새학기마크학교_백업_2026-11-17.mcworld` (수정 전 상태)

## 1. 모든 퀴즈 NPC 공통: 오답 버튼

오답 버튼의 명령(`say 다시 한번 생각해보세요.`)은 모두 아래 한 줄로 바꿉니다. 그 학생에게만 보입니다.

```
tellraw @initiator {"rawtext":[{"text":"§c다시 한번 생각해 보세요."}]}
```

## 2. 퀴즈 NPC 17명: 정답 버튼

정답 버튼의 명령(`say 정답입니다.`, `give @p wool …`)은 **모두 지우고** 아래 한 줄만 넣습니다.
- 표의 `qNN` 자리에 그 NPC의 번호를 넣습니다.
- 처음 맞히면 양털, 소리, 진행도(n/16)가 나옵니다.
- 이미 푼 문제를 다시 누르면 "이미 푼 문제예요"가 나옵니다.
- 16색을 다 모으면 전체 채팅에 축하 메시지가 뜹니다.

```
execute as @initiator run function quiz/q00
```

- q16은 보너스 문제입니다. 16색 완주 개수에는 들어가지 않습니다.

### 보건교사 대사 교체 (코로나 문항 → 감염병 예방 문항)

대화 칸에 아래 대사를 넣습니다. 정답은 그대로 **3번**이라 버튼 순서를 바꾸지 않아도 됩니다.

```
보건교사 안은영입니다. 감기와 독감을 예방하는 습관으로 올바르지 않은 것은 무엇일까요?

1번. 기침할 때는 옷소매로 입과 코를 가린다.
2번. 비누로 30초 이상 손을 씻는다.
3번. 아파도 참고 친구와 물병을 같이 쓴다.
```

> 함수 팩이 동작하지 않을 때는 정답 버튼에 아래 두 줄을 넣으세요. 양털 색은 바꿔서 씁니다. 반복해서 받는 것은 막지 못합니다.
> ```
> give @initiator lime_wool 1
> tellraw @initiator {"rawtext":[{"text":"§a정답입니다!"}]}
> ```

## 3. 안내 로봇 (`/tp @s -96 71 224`)

| 버튼 | 바꿀 내용 |
|---|---|
| 교가 듣기 | 버튼 종류가 **URL**이고 지금 주소가 비어 있습니다. 학교 누리집의 교가 페이지나 유튜브 주소를 넣으세요. |
| 학교 앨범보기 | 주소가 비어 있습니다. 학급 앨범이나 학교 누리집 주소를 넣으세요. |
| 교실로 바로 가기 | `tp @initiator -128 72 237` (`@p`를 `@initiator`로 바꿈) |

## 4. 투표 로봇 (`/tp @s -128 72 258`)

기존 버튼은 이전 방식(Num 점수판)이라 새 투표권 방식과 맞지 않습니다. 아래처럼 바꿉니다.

| 버튼 | 명령 (기존 명령은 모두 지우고 한 줄만) |
|---|---|
| 투표준비 | `function vote/setup` |
| 결과 확인 | `function vote/result` |
| 초기화 | `function vote/reset` |

> 투표 로봇은 학생도 누를 수 있습니다. 학생이 **초기화**를 누를까 걱정되면 로봇의 초기화 버튼은 지우세요. 교사는 채팅창에 `/function vote/reset`을 입력하면 됩니다. 학생은 슬래시 명령을 쓸 수 없습니다.

## 5. 투표실 커맨드 블록 (기호 1~4번)

버튼마다 커맨드 블록이 위아래로 두 개 있습니다.
- 아래 블록(y=73, 일반 커맨드 블록): 버튼을 누르면 표를 세는 블록입니다. 아래 명령으로 바꿉니다.
- 위 블록(y=74, 연쇄 커맨드 블록): 아래 블록 바로 뒤에 실행되는 순간이동 블록입니다. **명령을 지웁니다.**
  - 새 함수가 표를 센 뒤 투표한 학생을 직접 밖으로 보냅니다.
  - 위 블록을 남겨 두면 한 번 더 `tp @p`가 실행됩니다. 그러면 입구에서 기다리던 다음 학생까지 밖으로 보낼 수 있습니다.

| 부스 | 아래 블록 (y=73) 새 명령 | 위 블록 (y=74) |
|---|---|---|
| 기호 1번 (-130, 73, 241) | `function vote/cast1` | 명령 지우기 |
| 기호 2번 (-130, 73, 243) | `function vote/cast2` | 명령 지우기 |
| 기호 3번 (-130, 73, 245) | `function vote/cast3` | 명령 지우기 |
| 기호 4번 (-130, 73, 247) | `function vote/cast4` | 명령 지우기 |

동작: 투표권이 1인 학생만 표가 세어집니다. 투표권은 0이 되고 투표실 밖(-123, 72, 238)으로 이동합니다. 두 번째 투표는 세지 않고 "투표권이 없어요"라고 알려 줍니다.

## 6. 기타 정리

| 위치 | 내용 | 할 일 |
|---|---|---|
| 전담경찰관 김순경 (-128, 72, 234) | 이름·명령이 빈 버튼이 하나 있음 | 버튼 삭제 |
| 커맨드 블록 (-133, 69, 253) | `remove @p emerald 1`은 문법 오류 | 쓰지 않으면 지우기. 쓸 거라면 `clear @p emerald 0 1` |
| 커맨드 블록 (-133, 69, 252) | `scoreboard players add @a Money 100` (화폐 실험) | 쓰지 않으면 지우기 |
| 학급 규칙 칠판 5~8번 (-129~-126, 73, 231) | 잠겨 있어 학생이 쓸 수 없음 | 월드 빌더로 칠판 편집 → 잠금 해제 |

## 7. 교사용 명령 요약 (채팅창에 입력)

| 수업 단계 | 명령 |
|---|---|
| 시작 | `/function setup` · `/function class/gather` (운동장 집합) |
| 번호 받기 | 학생들이 번호 표지판 위에 선 뒤 `/function number/give`. 번호가 이름 아래와 Esc 목록에 표시됩니다. |
| 둘러보기·퀴즈 | `/function class/adventure` (블록 보호) · `/function quiz/show` (진행 상황) |
| 자리 뽑기 | `/function seat/draw` (교사를 뺀 학생에게 1번부터 겹치지 않게 무작위 배정) |
| 반장 선거 | `/function vote/setup` → 한 명씩 투표 → `/function vote/result` |
| 교실 꾸미기 | `/function class/build_on` → 끝나면 `/function class/build_off` |
| 다시 하기 | `/function quiz/reset` · `/function vote/reset` · `/function seat/reset` · `/function number/reset` |
| 모으기 | `/function class/gather` (운동장) · `/function class/classroom` (견본 교실) |
